# iPhone Sales Analysis Report
# My first report 
## Project Overview
This project provides a comprehensive data analysis of iPhone sales. The goal is to understand sales trends, customer preferences, and revenue generation across different iPhone models.

## Tools Used
* **Excel:** Data cleaning, transformation, and creating the interactive dashboard.
* **HTML:** Exporting and sharing the interactive view of the report.

## Project Structure
* `iphone_sales_report.xlsx`: The dataset and the core analysis.
* `iphone_sales_dashboard.html`: The interactive dashboard/report for quick view.
* `README.md`: Project documentation.

## Key Insights (Sample)
* Analyzed top-performing iPhone models based on sales volume.
* Identified peak sales periods and revenue distribution.
